# 🛒 StyleShop — Полная память проекта

## 📌 СТЕК

- React 18 + TypeScript + Vite
- Tailwind CSS + Framer Motion
- Firebase (Auth + Firestore)
- React Router v6
- react-intersection-observer (бесконечная подгрузка)

## 🧠 КЛЮЧЕВЫЕ КОМПОНЕНТЫ

- `AutoNav.tsx` — навигация с авторизацией, плавное подчёркивание, скрытие страниц по настройкам
- `GearBackground.tsx` — шестерёнка, поворачивается по скроллу (IntersectionObserver)
- `FloatingCartBar.tsx` — плавающая панель корзины внизу экрана (fixed)
- `Catalog.tsx` — бесконечная подгрузка товаров + переключатель вида (сетка/список)
- `Admin.tsx` — админка (товары, пользователи, статистика, настройки, генератор товаров)
- `SettingsContext.tsx` — управление видимостью страниц (Firestore)

## 🔐 АВТОРИЗАЦИЯ

- Регистрация / Вход / Выход
- Профиль пользователя (редактирование)
- Роли: `user` / `admin` (хранятся в Firestore)
- Админка видна только при `role === 'admin'`

## 🛒 КОРЗИНА

- Хранится в Firestore по `sessionId`
- Добавление, удаление, изменение количества
- Плавающая панель внизу (количество + цена + кнопка "Перейти в корзину")

## 📦 КАТАЛОГ

- Загрузка товаров из Firestore
- Бесконечная подгрузка (IntersectionObserver)
- Переключение вида: сетка / список (сохраняется в localStorage)
- Кнопка "В корзину" не вылезает за границы на телефоне

## ⚙️ АДМИНКА (вкладки)

1. **Товары** — CRUD + генератор товаров (5, 10, 20, 50, 100 шт)
2. **Пользователи** — список, назначение/снятие админа
3. **Статистика** — количество товаров, пользователей, админов
4. **Настройки** — вкл/выкл страницы (home, catalog, cart, profile, admin, login, register)

## 🧩 НАСТРОЙКИ (SettingsContext)

- Хранятся в Firestore: `settings/navigation`
- Влияют на видимость секций в `App.tsx` и кнопок в `AutoNav.tsx`
- Админка защищена от случайного отключения (рекомендуется)

## 📱 SNAP-SCROLL

- Вся лента в `App.tsx` обёрнута в `snap-y snap-mandatory`
- Переключение между секциями по скроллу (колёсико / палец)
- Секции: home → catalog → cart → profile → admin → login → register (условно)

## 🗄️ FIRESTORE СТРУКТУРА

- `users/{uid}` → email, displayName, role, phone, address
- `products/{id}` → name, price, image, description, inStock
- `carts/{sessionId}` → items: [{ productId, quantity }]
- `settings/navigation` → { home, catalog, cart, profile, admin, login, register }

## 🔧 ПОЛЕЗНЫЕ ФАЙЛЫ

- `src/utils/productGenerator.ts` — генератор товаров
- `src/hooks/useViewMode.ts` — переключение вида (grid/list)
- `src/hooks/useSession.ts` — sessionId для корзины
